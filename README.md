# SPVCI_5.5

Sistema de Punto de Venta y Control de Inventario (SPVCI), desarrollado en equipo para la materia de Programación Orientada a Objetos.

## Descripción

SPVCI_5.5 es un sistema que permite gestionar las ventas de un negocio y llevar el control de su inventario, aplicando los principios de la Programación Orientada a Objetos.

## Cómo ejecutarlo

1. Clona el repositorio:
   ```bash
   git clone https://github.com/up250297mhjp/Proyecto-POO-SPVCI.git
   cd Proyecto-POO-SPVCI
   ```
2. Ejecuta el programa:
   ```bash
   python proyecto.py
   ```

## Cómo colaborar

1. Haz `git pull` antes de empezar a trabajar.
2. Haz tus cambios y confírmalos con un mensaje claro:
   ```bash
   git add .
   git commit -m "Descripción de lo que hiciste"
   ```
3. Sube tus cambios con `git push`.

> No subas archivos con contraseñas o credenciales (como `.env`).
